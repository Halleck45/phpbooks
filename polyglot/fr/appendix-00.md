# Annexes

Ces trois annexes sont des tables de référence, pour les moments où il vous faut un fait précis plutôt qu'un chapitre. [A - Venir de Python, JavaScript ou Java](appendix-01-cheat-sheet.md) fait correspondre les constructions que vous connaissez déjà à leur écriture PHP, une ligne chacune. [B - PHP 8.0 à 8.5 en un coup d'œil](appendix-02-versions.md) liste ce que chaque version a apporté, pour que vous sachiez ce que le PHP de votre projet peut utiliser. [C - Vocabulaire](appendix-03-vocabulary.md) définit les mots qui reviennent dans les conversations PHP et nulle part ailleurs.
