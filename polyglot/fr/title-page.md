# 🐘 Et maintenant, PHP

**Un guide de PHP moderne qui se lit en deux à trois heures, pour les développeurs venus d'un autre langage.**

<img src="images/ch00-cover.png" alt="Un petit éléphant rond tient un panneau indicateur dont les flèches Python, JavaScript, Java et Go pointent toutes vers une même porte marquée PHP" width="480">

Vous savez coder, et on vient de vous confier un projet PHP, ou bien vous revenez à ce langage après des années passées ailleurs. Vous n'avez pas besoin d'un tutoriel, mais du delta entre ce que vous savez déjà et ce que PHP fait à sa manière : comment il s'exécute, comment il type, comment il organise le code en paquets, où il va vous surprendre, et à quoi ressemble le PHP d'aujourd'hui une fois l'ancienne réputation mise de côté.

Ce livre se lit en deux à trois heures. Chaque chapitre répond à une question, « comment PHP fait-il ça ? », puis passe à la suivante.

Le PHP décrit ici est PHP 8.5. Les fonctionnalités plus récentes que PHP 8.2 portent leur numéro de version, pour que vous sachiez ce que votre projet peut utiliser.
