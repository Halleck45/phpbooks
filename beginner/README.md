# The PHP Book

The book for *The Absolute Beginner* persona. Build with `make en`, `make fr`, `make build`, `make pdf`, `make illustrations`, `make lint` from this folder. Editorial conventions are in `SPEC.md`.

## For who 

This book is written for onboarding developer on PHP. It is written for a developer with 
computer science experience: base concepts like file, variable, object and classes are 
expected, although, they are also gently described in PHP terms. 

## Writing

Here are a few recommendations:

+ use code illustration as much as possible, and keep the code as small as possible. And not smaller, as the expression goes.
+ use pictures to keep the reading light and pleasant.
+ use aparté to mark noteworthy and short pieces of information.
+ use annex to group scattered information together

## Translation

The book is meant to be translated to other languages. Hence, we keep the language simple
and culturally neutral as much as possible, to allow for simple translation.

Pictures with text will have to be translated: keep that text to a minimum.
